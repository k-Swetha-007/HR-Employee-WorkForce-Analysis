HR Employee Workforce Analysis

Project Overview

This project analyzes HR employee data using Python to understand workforce trends and employee-related factors.

Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

Analysis Performed

- Age Distribution Analysis
- Distance From Home Analysis
- Education Analysis
- Job Involvement Analysis
- Environment Satisfaction Analysis
- Relationship Satisfaction Analysis
- Work-Life Balance Analysis
- Years at Company Analysis

Key Insights

- Identified workforce age distribution patterns.
- Analyzed employee satisfaction and engagement metrics.
- Studied work-life balance and training participation trends.
- Examined employee tenure and workforce characteristics.

Project Structure

- Dataset
- Project Notebook
- Output Visualizations

Outcome

Generated meaningful workforce insights through exploratory data analysis and data visualization.
